# ADR-0003: CIM-Life 綜合入口平台與純靜態 SPA 架構決策

## Status

Accepted (Updated 2026-08)

## Context

原專案曾規劃於單一 Repository 中同時維護「迎新電子名片收集」與「新生生活指南與工具」。

隨著專案發展與需求聚焦：
1. **電子名片與現場破冰系統**（Next.js / 雲端資料庫後端）已正式拆分至獨立專案與獨立團隊維護。
2. **CIM-Life 新生綜合服務平台**（全所開課課表、碩士畢業學分試算、研究室 209/310/313/919 擬真格局圖、抽籤大會舞台與生活指南）需要極致的隱私保護、極高的載入效能與零雲端託管維運成本。

## Decision

將本專案定位確立為 **「CIM-Life (中央資管通) · 碩士新生綜合服務與生活入口平台」**，並全面採用**純客戶端靜態單頁應用（Client-side Static SPA）**架構：

1. **純前端無伺服器架構 (Zero-Backend SPA)**：
   - 託管於 GitHub Pages，無冷啟動延遲，載入速度達毫秒級。
   - 資料隱私零外洩：使用者的個人選課、學分試算與歷年成績全數保存於本地瀏覽器 LocalStorage，不經過任何外部伺服器。

2. **模組化路由 (Modular Architecture)**：
   - `/timetable`：全所開課總表、週課表切換、多班合開智慧合併與個人選課底線標記。
   - `/tools/credit`：碩士畢業必選修學分門檻檢核與抵免試算器。
   - `/guide` & `/food`：選課技巧、校園資源與中大美食地圖。
   - `/seats` & `/stage/lottery`：209/310/313/919 研究室實體格局圖與大螢幕抽籤舞台模式。

3. **CIS 一鍵書籤小工具同步 (Bookmarklet Sync)**：
   - 開發安全透明的 Bookmarklet 腳本，直接於瀏覽器解析校務系統資料並回傳至本機 App，完全無需使用者輸入或提供帳號密碼。

## Consequences

### Positive
- **零資安隱私風險**：使用者選課與修課紀錄不離開本機，符合最高隱私標準。
- **零運維與託管成本**：透過 GitHub Pages 享受全球 CDN 靜態發佈與 100% 穩定度。
- **團隊邊界清晰**：名片系統與指南工具專注各自獨立專案，開發互不干擾。

### Negative / Trade-offs
- 跨裝置資料同步需仰賴使用者再次於新裝置執行 CIS 書籤小工具匯入。
