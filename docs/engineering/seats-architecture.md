# 研究室座位表架構與維護指南 (Seats Architecture & Maintenance Guide)

## 1. 核心架構與設計哲學 (Architecture & Philosophy)

本系統將「實體空間硬體幾何」與「動態學生座席名單」實施嚴格的**職責分離 (Separation of Concerns)**：

```text
src/data/seats.json          src/pages/SeatsPage.tsx
┌──────────────────────┐     ┌────────────────────────────────────┐
│  動態名冊資料庫       │ ──> │  靜態實體空間格局                   │
│  [209/310/313/919]   │     │  - 欄寬、走道軌道 (gaps)           │
│  "座號": "學生姓名"  │     │  - 門、白板、印表機、沙發、牆柱     │
└──────────────────────┘     └────────────────────────────────────┘
```

1. **實體空間格局 (`src/pages/SeatsPage.tsx`)**：
   * 定義研究室的物理幾何特徵（如總欄數、直排走道軌道、出入口門、長條白板、印表機、沙發及牆柱）。
   * 此處僅保留幾何座標與座號標籤（如 `{ type: "seat", label: "1-1" }`），**絕不硬編碼任何學生個人姓名**。
2. **座席分配資料庫 (`src/data/seats.json`)**：
   * 集中存儲每學年各研究室的抽籤或分配結果。
   * 結構極為簡潔，由房間 ID 對應座號與姓名：
     ```json
     {
       "209": { "1-1": "楊宜蓁", "4-2": "王閎立" },
       "310": { "4-3": "陳洺安" },
       "313": { "1-6": "沈佳潁", "2-3": "張壬郁" },
       "919": { "1-5": "侯育霖", "2-1": "胡莉敏" }
     }
     ```
3. **空位自動降級 (Graceful Fallback)**：
   * 若某座號在 `seats.json` 中未定義或值為空字串，畫面自動呈現 **「空」**（並套用虛線邊框樣式），毋須額外設定。

## 2. 每年名冊更新 SOP (Maintenance SOP for Maintainers)

每學年抽籤結束或學期中有座位更換時，維護者**完全不需要修改任何 TypeScript / React 頁面程式碼**：

1. 開啟 [`src/data/seats.json`](file:///c:/Users/g1014308/Documents/GitHub/Youchen/NCUIM2026-Fresher/src/data/seats.json)。
2. 找到對應的研究室代號（`"209"`、`"310"`、`"313"`、`"919"`）。
3. 修改或新增對應座號的學生姓名。
4. 儲存檔案並執行驗證指令：
   ```bash
   npm run typecheck && npm test && npm run build
   ```
5. 按照本專案規範提交（例如：`fix(data): update 115 academic year seat assignments`）。

## 3. 方位基準與平面配置規範 (Orientation & Layout Specifications)

### 3.1 統一方位基準：「面朝志希館大門」
所有研究室卡片標題右側均標註 **「面朝志希館大門」**。畫面上方（頂部）一律對齊志希館實體建築正門面向（朝南），讓新生對照空間方位時直觀無誤。

### 3.2 各研究室格局特性

| 研究室 | 總席數 | 格局特徵與硬體配置 |
| :--- | :--- | :--- |
| **209** | 20 席 | 4 排 × 5 列（座席 54px 寬）。頂部為出入口「門」（54px 寬筆直對齊 1-1）與「白板」（跨 2～4 欄），下方為出入口橫向走道。 |
| **310** | 27 席 | 5 排 × 5 列 + 額外席（6-1, 6-2），座席採用 46px × 48px 最適手機防溢比例。頂部為「門」（46px 寬對齊 1-1）與「白板」（跨 3～6 欄），右側包含「印表機」。 |
| **313** | 23 席 | 4 排結構（座席 54px 寬）。頂部設備排為「印表機」（44px）、「沙發」（44px）、「門」（54px 寬 × 44px 高，筆直對齊 4-1），底緣皆無縫貼齊下方走道。第 4 欄第 2 列為「牆柱」。 |
| **919** | 9 席 | 格局順時針轉 90 度改為**正北向**。頂部北側牆配置「印表機」（跨 3 欄）、「白板」與向下開之「門」；座席為 2 排 5 欄（1-5~1-1、2-5~2-1），具備上下雙橫向走道與中央縱向貫穿走道。 |

## 4. CSS Grid 排版工程機制 (CSS Grid Layout Mechanics)

### 4.1 走道軌道映射算法 (Aisle Column Mapping)
當研究室定義了直排間距陣列 `gaps: [...]` 時，CSS Grid 會在每個邏輯桌排欄位之間插入獨立的走道軌道：
$$\text{seatColumn}(\text{logicalCol}) = \text{leadingTracks} + \text{logicalCol} \times 2 + 1$$
此公式確保所有座席與跨欄設備（如白板、走道）均能以像素級精度定位在實體軌道上。

### 4.2 負邊距消除走道縫隙模式 (Negative Margin RowGap Cancellation)
為了使出入口的門、白板、印表機與沙發等固定牆面設備緊貼走道的虛線邊界，同時不破壞容器層級的全局 `rowGap`，在設備底部套用：
```tsx
marginBottom: -(hasRowAisles ? 0 : sizes.gap)
```
此模式成功消除了 6px 的 Grid Gap，達成擬真建築圖的無縫貼齊效果。

### 4.3 門方塊比例對稱 (Door Dimensions)
為避免門呈現單薄的膠囊狀，所有研究室的「門」均設置為：
- **寬度**：`width: "100%", minWidth: sizes.seat`，完美與下方的座位縱向邊界齊平。
- **高度**：209/310 為 40px（與白板等高），313 為 44px（與沙發、印表機等高），919 為 52px（與座席等高）。
